# Setting up GitHub Repository for C41 UNCC News App

## 1. Create a GitHub Repository

1. Go to GitHub.com and log in to your account
2. Click the "+" button in the top right, then "New repository"
3. Name: `c41-uncc-news-app`
4. Description: "UNCC Latest News application built with Angular, Node.js, and MongoDB"
5. Choose "Private" (recommended for coursework)
6. Click "Create repository"

## 2. Initialize your local repository

```bash
cd C:\Users\Chin\finalproject\c41-app

# Initialize git
git init

# Add all files
git add .

# Commit changes
git commit -m "Initial commit: UNCC News App"

# Add remote repository
git remote add origin https://github.com/hshb7/c41-uncc-news-app.git

# Push to GitHub
git push -u origin main
```

> Replace YOUR_USERNAME with your actual GitHub username
